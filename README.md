# SeatBot

**SeatBot** — менеджер поездок из колледжа в Минск для одного водителя (админа).
Пассажиры бронируют места (4 свободных), платят с депозита, который админ пополняет налом.

## Возможности

### Водитель (админ)
- Создание поездок: время отправления, цена, авто-апрув, видимость
- Апрув / реджект кандидатов, отметка no-show, завершение и отмена поездок
- Скрытие/публикация поездок (видны всем или только забронировавшим)
- Управление депозитом клиентов (пополнение / списание)
- Чёрный список (бан) и VIP (бесплатные поездки + всегда авто-апрув)
- Рассылка по всем пользователям
- Статистика: по клиентам (кто сколько катался и заплатил) и общая

### Пассажир
- Список ближайших поездок с ценой и свободными местами
- Бронирование места (оплата с депозита)
- Мои брони и статус (ожидает / одобрено / отклонено)
- Свой депозит и статистика поездок

## Быстрый старт
- Python 3.13+, PostgreSQL, Redis
- `cp secret_data/config.example.toml secret_data/config.toml` и заполнить
- `just install-dev`
- `just migrate`
- `just run` (или `just watch`)

## Стек
aiogram 3 + aiogram-dialog, dishka, adaptix, SQLAlchemy 2 + asyncpg + alembic,
Redis, apscheduler. Архитектура DDD по гайдлайну Tunnex.
